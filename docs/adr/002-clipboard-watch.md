# ADR-002: クリップボード変更監視・機密判別・自動ペーストの方式

**日付:** 2026-10-17
**ステータス:** 決定済み

## 背景
コピーした内容を1秒以内に履歴へ追加し、パスワード管理アプリ由来のコピーは記録しない。公式の `tauri-plugin-clipboard-manager` には変更監視の機能が無い。選んだ履歴を元のアプリへ自動で貼り付ける。

## 決定
- 変更監視とクリップボードの読み書きは clipboard-rs 0.3.5 を `=0.3.5` で固定して使う。macOS は `NSPasteboard.changeCount` のポーリング(既定 500ms)、Windows は `WM_CLIPBOARDUPDATE` によるイベント駆動。`start_watch()` はブロッキングのため専用スレッドで動かす。
- clipboard-rs は自作の trait(`ClipboardSource`・`ClipboardWriter`)で包み、ビジネスロジックからは trait だけを参照する。差し替え時の変更範囲をアダプタ1ファイルに限定する。
- 公式 clipboard-manager プラグインは使わない。読み書きを clipboard-rs に一本化し、自分で書き込んだ内容を記録しない処理(自己書き込みの抑止)を Rust 側の1か所に集めるため。フロントエンドからクリップボードに直接触れない。
- 機密判別: macOS は `org.nspasteboard.ConcealedType`・`TransientType`・`AutoGeneratedType` と旧来の独自型(`de.petermaurer.TransientPasteboardType`、`com.typeit4me.clipping`、`Pasteboard generator type`、`com.agilebits.onepassword`)、Windows は `ExcludeClipboardContentFromMonitorProcessing`・`CanIncludeInClipboardHistory`(値 0)・`Clipboard Viewer Ignore` の有無で判定する。加えて、設定した除外アプリ(コピー元アプリ)で判定する。コピー元が分からない場合の扱いは設定で選ぶ。
- 自動ペーストは enigo 0.6.1 を `=0.6.1` で固定して使い、`KeySender` trait で包む。macOS でアクセシビリティ権限が無い場合は、再コピーのみに切り替え、権限の案内(S4)を出す。

## 理由
- clipboard-rs は macOS・Windows の両方で変更監視を提供し、型名(フォーマット名)の一覧を取得できるため、機密判別にも使える。
- 非公式の Tauri プラグイン(clipboard-x 等)は clipboard-rs に依存するため、直接 clipboard-rs を使えば依存が1段減る。
- trait で包むことで、clipboard-rs・enigo(いずれも 1.0 未満)の破壊的変更や、OS API 直呼びへの切り替えに備えられる。テストでは偽の実装を使える。

## 却下した代替案
- 公式 clipboard-manager + 自前ポーリング: Windows では Microsoft が `GetClipboardSequenceNumber` のポーリングを非推奨としている。
- tauri-plugin-clipboard-x: clipboard-rs に依存し、単独メンテナへの依存が二重になる。
- OS API の直接呼び出し(CGEvent / SendInput 等): 依存は減るが、プラットフォーム別の unsafe コードが増える。trait の裏で将来切り替えられるようにしておく。

## 影響
- clipboard-rs・enigo は単独メンテナ・1.0 未満で、enigo は "early alpha" と明記され、次のリリースで破壊的変更が予定されている。バージョンを固定し、更新は手動で行う。
- 機密判別は規約ベースで、コピー元アプリが型を設定しなければ検知できない(ブラウザのパスワード拡張など)。除外アプリの設定で補う。
- macOS のペーストボードプライバシー(macOS 15.4 以降のプレビュー機能)で、ポーリングによる読み取りに警告が出る可能性がある(未確認。実機で確認する)。
- コピー元アプリの取得(macOS の最前面アプリ、Windows の `GetClipboardOwner`)と実行中アプリの一覧には、clipboard-rs 以外の OS API が必要。使う crate は、事前の試作(スパイク)で決める。
